# API的使用

## **课程核心**
- 前言：批量问卷/文本分析人工处理受限，大模型API可高效解决
- 课程目标：掌握大模型API批量处理任务方法；挖掘业务提效机会

## **一、千问API批量处理文本任务**
- 业务需求：1万+非结构化产品调研主观反馈，1天内分析待改进点
- 技术实现：用langchain框架简化代码，安装依赖pip install langchain_community dashscope
- 代码逻辑：从Excel读取反馈，调用千问API分析分类，输出结果
- 模型替换：修改代码中model_name，参考百炼模型调用文档

## **二、无编程基础：灵码辅助实现**
- 核心能力：自然语言描述需求，灵码转化为可执行代码
- 部署环境1：阿里云函数计算FC（推荐）
	- 1. 选模板【直接部署】，创建并部署环境
	- 2. 单击函数进入编程环境
	- 3. 新建main.py，终端执行pip install -r requirements.txt装依赖
	- 4. 用灵码组件输入提示词（可附API代码参考提升准确性）
	- 5. 复制代码到main.py，替换个人API Key
	- 6. 终端执行python main.py运行，调试需调整提示词重试
- 部署环境2：本地编程环境，参考官方指引下载灵码
- 团队协作：非技术人员可向技术岗提需求+实现建议，加速开发

## **三、阿里云大模型API调用要点**
- 服务特点：按量付费、开箱即用，提供千问+开源大模型API
- 模型选择：小参数量→调用快、成本低；大参数量→适配复杂场景
- 特色能力：Qwen-VL视觉理解，可实现拍照改作业等应用
- 参考文档：模型调用细节可查阅官方相关文档

## **四、课程小结与拓展**
- 核心收获：掌握代码集成大模型API实现复杂业务的方法
- 场景拓展：结合其他算法模型，如语音转文字+大模型做客服质检
- 业务思考：挖掘大模型与自身业务结合点，实现智能化、提效组织工作
