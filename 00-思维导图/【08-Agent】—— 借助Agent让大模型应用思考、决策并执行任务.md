# Agent

## **课程核心目标**
- 了解大模型Agent定义与解决的问题
- 了解人机交互前沿方向，激发创新思考

## **一、认识大模型Agent**
- 定义：基于大语言模型、能借工具与外部交互的计算机程序，又称智能体/代理
- 类比：大模型=大脑，工具=四肢，具备感知、思考、行动能力
- 核心能力1：记忆能力
	- 短期记忆：对话历史/提示词/搜索反馈，随会话结束消失，受上下文长度限制，有recency问题
	- 长期记忆：业务记录/知识库，存储于外部向量/文档库，支撑私有/专业领域问答
- 核心能力2：规划能力
	- 任务分解
		- 思维链CoT：拆解为链式步骤，可结合工具/代码执行，便于监控
		- 思维树ToT：构建树形分支，多路径探索后选最优，适配高不确定性问题
		- 思维图GoT：ToT的工程优化，支持回溯/剪枝；XoT整合各类分解方案
	- 推理与反思
		- ReAct方法：推理+行动+观察+循环，结合环境反馈调整
		- ReAct-Agent运行逻辑：判断解答能力→选工具→生成指令→调用工具→反馈再判断
		- ReAct提示词模版：含问题/思考/行为/输入/结果，支持多轮思考至解决问题
- Agent与大模型的区别
	- 可借插件与外部交互，实现计算机程序类操作
	- 主动推理、纠错、完成任务，支持进度同步/自主执行
	- 能拆解复杂任务，完成建网站/开发游戏等工作
	- 可自我迭代，吸取历史经验持续成长
	- 可接入领域知识库/工具，完成特定领域任务

## **二、Agent应用场景**
- 简单任务：发送邮件、查询天气
- 复杂任务：搭建网站、写文章、制定营销策略、开发软件原型
- 案例：写文章并发布，覆盖调研/选题/撰稿/润色/发布/优化/监测全流程
- 开源应用示例：AutoGPT（开源Agent程序）、AgentGPT（网页可视化部署Agent）

## **三、ModelScope-Agent框架实践**
- 核心能力：文本/图片/视频/语音生成，单Agent含角色扮演/LLM调用/工具使用等能力
- 技术特点
	- 实现简单：指定角色/模型/工具即可，框架自动编排工作流
	- 资源丰富：内置多模型接口+多工具，支持定制
	- 高扩展性：统一注册机制，方便扩展Agent能力
	- 低耦合性：可单独使用内置组件，不绑定上层Agent
- 能力演示
	- 完成简单任务：调用插件生成视频等内容
	- 完成多步骤任务：分析请求、安排执行顺序并依次完成
	- 提取工具参数：从多轮对话中提取信息，保障体验连贯
	- 检索式问答：加载知识库/搜索插件实现专业问答
- 已集成工具：网页浏览/搜索、代码解释器、高德天气、文/图/音/视频生成等，支持第三方工具（如LangchainTool）
- 体验方式：访问魔搭空间在线体验；下载代码运行本地案例

## **四、Multi-Agent多智能体**
- 定义：多个Agent分工协作完成任务，各专注擅长领域，提升效率与质量
- 单Agent与多Agent对比：单Agent完成复杂任务效果有限，多Agent分工更专业
- 角色分工示例：写文章的调研/创作/语法检查/校对专家
- 协作模式：Agent间互相指派任务；主Agent带领从Agent协同工作
- 项目示例
	- MetaGPT：单prompt组建AI开发团队，自动分工生成软件+配套文档，支持“消息版”协作模式
	- AgentScope：阿里多智能体开发平台
		- 特点：高易用/高鲁棒/分布式，支持容错控制、多模态数据管理、并行优化
		- 本地模型部署：支持ollama、Flask+Transformers等库
		- 支持服务：网络搜索、数据查询/检索、代码执行等
		- 能力兼容：LangChain、ReAct智能体，支持SQL/RAG对话等
		- 样例应用：狼人杀游戏、分布式辩论/仿真等
- 其他开源框架
	- Camel AI
	- AutoGen（微软）：低代码构建多角色对话应用，优化推理与记忆能力
	- AgentVerse：学术场景为主，含问题解决/模拟器框架，模拟社会实验
	- 斯坦福小镇：研究型多智能体社区，探索智能体社会关系，基于向量存储记忆

## **五、大模型Agent系统的完善方向**
- 优化信息输入：精简提示词/压缩历史记忆，避免巨量信息降低准确率、增加成本
- 提升规划能力：设计步骤拆解衡量方法、自动化错误监测方案，支持人工介入修正
- 合理分配模型任务：综合使用不同规格大模型，按任务难度分配，降低运行成本

## **六、课程小结**
- Agent核心：借工具与外部交互，从“教做”到“帮做”，具备记忆/规划能力
- 协作模式：支持单Agent独立工作、多Agent分工协作
- 发展现状：仍有完善空间，懂业务+懂Agent可推动业务创新
