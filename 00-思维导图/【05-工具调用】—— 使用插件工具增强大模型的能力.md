# 工具调用
## **课程前言**
- 大模型API可处理批量任务，但非所有任务都能完美解决
- 示例：大模型计算小学复杂算术题易出错，可借助插件解决
## **课程目标**
- 了解大模型插件的使用方法
- 学习大模型插件原理
- 掌握开发自定义插件的相关知识
## **1 什么是插件**
- 定义：增强和扩展基础大模型功能的软件组件
- 典型插件分类
  - 基础工具：计算器、时钟、天气、股票行情
  - 实时消息类：体育赛事报道、实时热点新闻
  - 能力拓展类：图片生成、语音合成、代码解释器
- 企业定制插件：对接开放平台API，如飞猪查酒店/订机票，提供企业差旅服务
## **2 插件演示**
- 大模型短板：数学计算能力弱，复杂运算易出错，编程实现也无实际运行代码
- 计算器插件：解决393x285等计算问题，实现实际运算，输出准确结果
- 代码解释器插件：运行Python代码完成计算，结果准确
- 操作平台：百炼平台可视化界面
- 更多插件应用
  - 官方插件：图片生成插件制作广告图片
  - 自定义插件：查询实时天气、阿里云服务器等云资源
## **3 工作原理**
- 核心逻辑：与人类使用工具流程一致
- 执行步骤
  1. 接收用户输入
  2. 判断是否需要使用工具，选择合适插件
  3. 调用插件并获取返回结果
  4. 结合结果推理生成最终输出
## **4 阿里云大模型API插件支持**
- 百炼平台：基于千问API构建应用，可查看预置插件能力，支持添加自定义插件
- 灵积产品：提供兼容OpenAI API的千问API，支持OpenAI function call能力
- 优势：面向中文用户、满足国内备案要求，无需修改代码替换OpenAI API
## **本节小结**
- 插件实现大模型与三方应用交互，完成能力增强和拓展
- 可结合大模型与业务系统现有功能，如建待办、抢会议室、查阿里云资源
- 插件增强的大模型应用如同私人助理，可按指令完成各类工作
