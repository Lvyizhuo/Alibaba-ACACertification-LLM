

## 一、课程背景与目标
1. **背景**：公司产品调研收集到大量非结构化问卷，人工或单次大模型分析难以应对，需借助大模型服务API处理。
2. **目标**：了解如何用大模型服务API自动处理任务，发现业务中借助大模型提效的机会。

## 二、借助千问API自动完成文本处理任务
1. **需求**：统计产品调研中用户认为产品有待改进的方面，如价格、售后、体验等，面对1万多份非结构化主观反馈需1天内完成分析。
2. **解决方案**
    - **代码实现**：使用langchain框架简化代码，运行前安装 `pip install langchain_community dashscope` 依赖，调整代码从Excel文件（`data/file_path_feedback.xlsx`）读取反馈并分类，借助千问API分析并打印结果。可替换代码中 `qwen - max` 值选用其他模型，参考百炼的模型调用获取更多 `model_name` 取值。
    - **灵码辅助（无编程基础）**
        - **环境准备**：利用阿里云函数计算FC调用灵码，通过准备好的模板创建函数计算应用，函数计算控制台在线IDE集成灵码插件。
        - **操作步骤**：
            - 点击模板，选择【直接部署】，点击【创建并部署环境】。
            - 环境创建完成后，单击函数进入编程环境。
            - 进入代码编辑器界面，新建 `main.py` 文件，点击 `Terminal > New Terminal`，在命令行输入 `pip install -r requirements.txt` 安装依赖。
            - 使用灵码组件输入提示词（因训练数据时效性，可给灵码代码参考）。
            - 将灵码写好的代码复制到 `main.py` 文件，替换 `api_key="sk - xxxx"` 中的 `sk - xxx` 为自己的API Key，在命令行执行 `python main.py` 运行代码查看结果。若灵码输出代码无效，调整提示词重试。

## 三、阿里云上大模型服务的API调用
1. **服务特点**：阿里云提供按量付费、开箱即用、多种参数规模的千问及开源大模型服务API。
2. **模型参数与应用关系**：满足业务需求前提下，参数规模小，API调用速度快、成本优；参数规模大，能应对复杂业务场景，更多细节参考模型调用。
3. **Qwen - VL应用**：可通过Qwen - VL视觉理解能力实现拍照改作业等应用。

## 四、应用拓展与总结
1. **拓展思路**：除批量文本处理，可结合其他算法模型处理更复杂任务，如声音转文字模型结合大语言模型实现客服质检。鼓励在业务中寻找与大模型结合的机会，提升工作效率。
2. **总结**：通过案例介绍在代码中集成大模型服务API实现复杂业务场景的方法，帮助理解调用大模型能力。
